# Finance Tracker CLI

Sistema de finanzas y gestión de productos en consola, con persistencia en SQLite.  
Permite agregar productos, ver inventario, y preparar la base para registrar ventas y calcular ganancias.

---

## 📌 Características

- Gestión de productos:
  - Agregar productos con nombre, costo, precio y cantidad.
  - Visualizar inventario actualizado.
- Persistencia de datos con SQLite.
- Terminal limpia y organizada.
- Mensajes de error en color (usando `colorama`).
- Preparado para futuras funciones:
  - Registro de ventas.
  - Cálculo automático de ganancias.
  - Exportación a Excel.

---

## 🛠 Tecnologías usadas

- Python 3.x
- SQLite3
- Colorama (para mensajes en color)
